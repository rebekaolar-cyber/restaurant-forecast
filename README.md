# restaurant-forecast

Website and staffing forecast for one restaurant. Test project, fake data only.

- `site/` — public website and the dashboard behind a login
- `forecast/` — Python forecast (guests per shift, then staff from rules)
- `supabase/` — database migrations and tests
- `.github/workflows/` — the nightly job

See `CLAUDE.md` for the stack, the shared database contract and the rules that are never traded for speed.
